## ⚡ О проекте

**ValSkinAlarm** — это портативное десктопное приложение для Windows, созданное для отслеживания появления желанных скинов в вашем личном магазине VALORANT. 

Вам больше не нужно каждый день запускать игру только ради того, чтобы проверить магазин:
1. Вы выбираете интересующие скины в каталоге (например, *«Прайм Вандал»*, *«Жнец»*, *«Куронами»*).
2. Приложение проверяет ротацию вашего магазина.
3. Как только скин появляется в магазине — на ваш рабочий стол мгновенно приходит **всплывающее звуковое уведомление Windows**!

## ✨ Ключевые возможности

- 🛒 **Ассортимент магазина в реальном времени**:
  - Отображает 4 текущих предложения с рендерами оружия в высоком разрешении, ценами и названиями на русском и английском.
  - Точный таймер обратного отсчета до сброса магазина в игре.
  - Интеллектуальное кэширование: если магазин уже проверялся сегодня после утреннего сброса (06:00), повторные запросы не тратят ресурсы.
  - Подсветка скинов из вашего вишлиста яркой акцентной рамкой `⭐ В ВАШЕМ ВИШЛИСТЕ`.
- 📖 **Полный каталог скинов (1370+ предметов)**:
  - Мгновенная загрузка из локального кэша за 0.03 секунды.
  - **Двуязычный поиск**: ищите как по-русски (*«Жнец»*, *«Прайм»*, *«Куронами»*, *«Дракон»*), так и по-английски (*«Reaver»*, *«Prime»*, *«Kuronami»*, *«Elderflame»*).
  - Удобная фильтрация по видам оружия (*Вандал, Фантом, Оператор, Шериф, Ножи / Холодное оружие* и др.).
  - Добавление любого скина в отслеживание в один клик (`☆ Отслеживать` → `★ В вишлисте`).
- 🤖 **Тихий фоновый демон (Автозапуск с Windows)**:
  - Встроенный переключатель прямо в окне: **«Демон при старте Windows»**.
  - При включении ПК демон запускается в фоне:
    - Если магазин за сегодня уже проверялся и совпадений нет — **мгновенно завершает работу**, не нагружая процессор и память.
    - Если магазин обновился и в нем есть скин из вишлиста — отправляет уведомление на рабочий стол и выключается.
- 🎨 **Современный адаптивный UI**:
  - Интерфейс на CustomTkinter в стилистике VALORANT.
  - Автоматическая адаптация под системную тему Windows (темная или светлая).
- 🔒 **Безопасность**:
  - Никаких паролей! Вся работа происходит локально через сессию вашего Riot Client или официальный Riot API.
  - Никаких тяжелых СУБД — все настройки хранятся в локальных JSON-файлах.

## 🛠️ Запуск из исходного кода (Python)

Если вы хотите запускать или модифицировать код напрямую:

### 1. Клонирование репозитория
```bash
git clone https://github.com/RobarII/val-skin-alarm.git
cd val-skin-alarm
```

### 2. Установка зависимостей
Требуется Python 3.10+:
```bash
pip install -r requirements.txt
```

### 3. Настройка окружения
Скопируйте пример файла конфигурации:
```bash
copy .env.example .env
```
Откройте [`.env`](.env) в текстовом редакторе и укажите параметры:
```env
# Персональный Riot API ключ разработчика
# Получить можно бесплатно: https://developer.riotgames.com/
RIOT_API_KEY=RGAPI-ваш-ключ-здесь

# Регион вашего аккаунта (europe, americas, asia, esports)
RIOT_REGION=europe
```

> 💡 **Подсказка**: Вы можете запустить приложение и без ключа в `.env` — оно успешно подхватит сессию запущенного Riot Client или запустится в локальном режиме.

### 4. Запуск
```bash
# Обычный запуск с графическим интерфейсом:
python main.py

# Запуск проверки в режиме тихого демона:
python main.py --daemon

# Тест всплывающего уведомления Windows:
python main.py --test-toast
```

## 🎮 Инструкция по использованию

1. **Регистрация профиля**:
   - При первом запуске введите ваш игровой ник и тег (например: `RobarOwO#2977` или `TenZ#0000`).
   - Выберите ваш регион (*Europe / na / ap / kr*).
   - Нажмите **«Сохранить и продолжить»**. Данные сохранятся локально, окно больше не побеспокоит вас.

2. **Выбор скинов (Вишлист)**:
   - Перейдите на вкладку **«📖 Каталог скинов»**.
   - Найдите нужный скин через строку поиска (на русском или английском) или отфильтруйте по оружию.
   - Нажмите кнопку **«☆ Отслеживать»** на карточке скина — она станет активной **«★ В вишлисте»**.

3. **Просмотр магазина**:
   - Перейдите на вкладку **«🛒 Ассортимент магазина»**.
   - Если запущен Riot Client, нажмите **«🔄 Обновить»** для получения актуальных 4 скинов.
   - Для проверки работы оповещений нажмите **«🎲 Демо-магазин»** — приложение сымитирует ротацию магазина, подставив скины из вашего вишлиста и вызвав будильник.

4. **Автозапуск**:
   - В верхней панели включите тумблер **«Демон при старте Windows»**.
   - Теперь при каждом включении компьютера магазин будет тихо проверяться в фоне без открытия окон.
