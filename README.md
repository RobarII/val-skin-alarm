## О проекте

**ValSkinAlarm** — портативное десктопное приложение для Windows, созданное для отслеживания появления нужных скинов в личном магазине VALORANT.

Вам больше не требуется запускать саму игру ради проверки магазина:
1. Вы выбираете интересующие скины в каталоге (например, *«Прайм Вандал»*, *«Жнец»*, *«Куронами»*).
2. Приложение полностью автономно находит установленный Riot Client и запускает его в системном трее Windows.
3. Программа считывает ротацию вашего магазина.
4. При появлении нужного скина в ассортименте на рабочий стол отправляется звуковое системное уведомление Windows.

## Ключевые возможности

- **Полная автономность**:
  - Никаких API-ключей, токенов и ручной настройки конфигурации.
  - Программа автоматически ищет установленный Riot Client на компьютере (через системные манифесты, реестр Windows и диски).
  - При необходимости программа сама запускает Riot Client в скрытом фоновом режиме в системном трее (`--launch-background-mode`).
  - Саму игру VALORANT запускать не нужно.

- **Ассортимент магазина в реальном времени**:
  - Отображение 4 текущих предложений с рендерами оружия, ценами и названиями на русском и английском языках.
  - Таймер обратного отсчета до сброса магазина в игре.
  - Кэширование: если магазин уже проверялся сегодня после утреннего сброса (06:00), повторные запросы не тратят ресурсы.
  - Подсветка скинов из вишлиста акцентной рамкой и статусом «В вашем вишлисте».

- **Каталог скинов (1370+ предметов)**:
  - Быстрая загрузка из локального кэша за 0.03 секунды.
  - **Двуязычный поиск**: поддержка поиска по русским (*«Жнец»*, *«Прайм»*, *«Куронами»*, *«Дракон»*) и английским (*«Reaver»*, *«Prime»*, *«Kuronami»*, *«Elderflame»*) наименованиям.
  - Фильтрация по видам оружия (*Вандал, Фантом, Оператор, Шериф, Ножи / Холодное оружие* и др.).
  - Добавление любого скина в отслеживание в один клик.

- **Тихий фоновый демон (Автозапуск с Windows)**:
  - Встроенный переключатель «Демон» в окне приложения.
  - При включении компьютера демон запускается в фоне:
    - Если магазин за текущие сутки уже проверялся и совпадений нет — мгновенно завершает процесс, не нагружая систему.
    - Если магазин обновился и содержит скин из вишлиста — отправляет уведомление на рабочий стол и завершает работу.

- **Интерфейс**:
  - Минималистичный UI на CustomTkinter в стилистике VALORANT.
  - Автоматическая адаптация под системную тему Windows (темная или светлая).

## Быстрый старт (Портативный EXE — без установки Python)

   [Скачать ValSkinAlarm.exe (Последний релиз)](https://github.com/RobarII/val-skin-alarm/releases/latest)
2. Поместите `.exe` в любую удобную папку и запустите.
3. Программа готова к работе: она автоматически обнаружит аккаунт и начнет отслеживать ассортимент.

## Запуск из исходного кода (Python)

### 1. Клонирование репозитория
```bash
git clone https://github.com/RobarII/val-skin-alarm.git
cd val-skin-alarm
```

### 2. Установка зависимостей
Требуется Python 3.10+:
```bash
pip install -r requirements.txt
```

### 3. Запуск
```bash
# Запуск с графическим интерфейсом:
python main.py

# Проверка в режиме тихого демона:
python main.py --daemon

# Проверка системного уведомления Windows:
python main.py --test-toast
```

## Инструкция по использованию

1. **Регистрация профиля**:
   - При первом запуске введите ваш игровой ник и тег, либо нажмите «Определить автоматически из Riot Client».
   - Выберите регион (*europe / na / ap / kr*).
   - Нажмите «Сохранить и продолжить». Профиль сохраняется локально в `data/profile.json`.

2. **Выбор скинов (Вишлист)**:
   - Перейдите на вкладку «Каталог скинов».
   - Найдите нужный скин через строку поиска или категорию оружия.
   - Нажмите «Отслеживать» на карточке скина — статус изменится на «В вишлисте».

3. **Просмотр магазина**:
   - Перейдите на вкладку «Ассортимент магазина».
   - Нажмите «Обновить» — программа сама обратится к Riot Client и покажет актуальные 4 скина.
   - Для проверки системных оповещений Windows нажмите кнопку «Тест».

4. **Автозапуск**:
   - В верхней панели включите переключатель «Демон».
   - При включении компьютера магазин будет проверяться в фоне без открытия графического окна.

5. **Обновление программы**:
   - Приложение проверяет наличие обновлений на GitHub при запуске.
   - При обнаружении новой версии в верхней панели отображается кнопка обновления.
   - В окне обновления доступна кнопка «Скачать и обновить» для автоматической загрузки и перезапуска.
   - Проверка из командной строки:
     ```bash
     ValSkinAlarm.exe --check-update
     ```

6. **Удаление фонового демона (Uninstall)**:
   - В интерфейсе: перейдите в «Настройки» и нажмите «Удалить демона из реестра».
   - Из командной строки:
     ```bash
     ValSkinAlarm.exe --uninstall
     ```
   *(Удаляет запись из ветки реестра Windows `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`).*
